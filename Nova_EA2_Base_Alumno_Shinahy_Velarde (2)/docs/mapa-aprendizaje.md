# Mapa de aprendizaje hasta el cierre
1. HTML semántico, encabezados, cascada y variables CSS: public/index.html y assets/css/styles.css.
2. Responsive, Flexbox/Grid y formularios: los mismos archivos; probar 320/768/1440 px y zoom.
3. Calidad, SEO y revisión: metadatos del head, README, docs/pruebas.md y PR.
4. Brief y modelo: docs/modelo-continuidad.md. Contexto del cliente: consultar soporte y registrar
   una incidencia ficticia. Usuarios: solicitante y técnico. Meta: confirmar y seguir una práctica.
5. JSON, DOM seguro, eventos, validación y ayuda: catalogo.js, interaccion.js y ui.js.
6. Integración: ea2-logica.js, ea2-ui.js, ea2.css y workflow calidad.yml; Preview y producción.
7. Preparación EF: corregir observaciones y repasar conceptos con el portal; el EF es teórico.

El alumno implementa lo nuevo señalado por R1 a R4. El resto sirve como base de aprendizaje.
GA4/GTM, autenticación de Supabase, dominio y servidor de datos se estudian conceptualmente;
este ZIP no configura cuentas ni publica recursos. Los eventos se guardan solo en memoria.
No es necesario tocar información de otra persona ni comprar servicios.
